# Use Case Description — UC-21 ถึง UC-35

## ส่วนที่ 2 (ต่อ): Member (สมาชิก)

### UC-21: ดูสายการแข่งขัน (View Live Bracket)

| หัวข้อ | รายละเอียด |
|--------|-----------|
| ชื่อกรณีการใช้งาน | UC-21: ดูสายการแข่งขัน (View Live Bracket) |
| ตัวแสดงแทน (Actors) | สมาชิก (Member) |
| เงื่อนไขก่อนเริ่ม | ทัวร์นาเมนต์อยู่ในสถานะ "Open" หรือ "Finished" และมีการจับคู่แมตช์แล้ว |
| ลำดับขั้นตอนการทำงาน | 1. ผู้ใช้งานกดปุ่ม "View Bracket" ในหน้าโหวตหรือหน้ารายละเอียดทัวร์นาเมนต์ <br> 2. ระบบดำเนินการดึงข้อมูลแมตช์ทั้งหมดจากฐานข้อมูล และจัดกลุ่มตามรอบการแข่งขัน <br> 3. สายการแข่งขันถูกแสดงผลในรูปแบบแผนผังต้นไม้ แมตช์ที่เสร็จสิ้นแสดงชื่อผู้ชนะ ส่วนแมตช์ที่ยังไม่ดำเนินการแสดงสถานะรอ <br> 4. ผู้ใช้งานสามารถกลับไปยังหน้าโหวตหรือหน้ารายละเอียดทัวร์นาเมนต์ได้ |
| เงื่อนไขหลังจบ | สายการแข่งขันพร้อมผลการแข่งขันแต่ละรอบถูกแสดงผลบนหน้าจอ |

### UC-22: แชทสด (Live Chat)

| หัวข้อ | รายละเอียด |
|--------|-----------|
| ชื่อกรณีการใช้งาน | UC-22: แชทสด (Live Chat) |
| ตัวแสดงแทน (Actors) | สมาชิก (Member) |
| เงื่อนไขก่อนเริ่ม | ผู้ใช้งานเข้าสู่ระบบแล้ว ทัวร์นาเมนต์อยู่ในสถานะ "Open" และมีแมตช์กำลังดำเนินอยู่ |
| ลำดับขั้นตอนการทำงาน | 1. ส่วนแชทสดถูกแสดงผลในหน้าการโหวต <br> 2. ผู้ใช้งานพิมพ์ข้อความและกดปุ่มส่ง <br> 3. ข้อความถูกบันทึกลงฐานข้อมูลและแสดงผลแบบ Real-time ให้ผู้เข้าร่วมทุกคน <br> 4. ข้อความที่ไม่เหมาะสมสามารถถูกรายงานโดยผู้ใช้งานผ่านปุ่มรายงาน |
| เงื่อนไขหลังจบ | ข้อความถูกบันทึกและแสดงผลในส่วนแชทสดของหน้าโหวต |

### UC-23: ดูสรุปผลการแข่งขัน (View Summary)

| หัวข้อ | รายละเอียด |
|--------|-----------|
| ชื่อกรณีการใช้งาน | UC-23: ดูสรุปผลการแข่งขัน (View Summary) |
| ตัวแสดงแทน (Actors) | สมาชิก (Member) |
| เงื่อนไขก่อนเริ่ม | ทัวร์นาเมนต์อยู่ในสถานะ "Finished" (การแข่งขันทุกรอบดำเนินการจนเสร็จสิ้น) |
| ลำดับขั้นตอนการทำงาน | 1. ระบบตรวจสอบว่าทัวร์นาเมนต์อยู่ในสถานะ "Finished" <br> 2. ข้อมูลผลการแข่งขันทุกรอบถูกดึงจากฐานข้อมูลและจัดเรียงตามรอบ <br> 3. หน้าสรุปผลถูกแสดงผล ประกอบด้วย รูปภาพและชื่อผู้ชนะเลิศ (Champion) พร้อมสถิติการโหวตแต่ละรอบ <br> 4. สายการแข่งขันที่สมบูรณ์พร้อมชื่อผู้ชนะแต่ละแมตช์ถูกแสดงผลเพิ่มเติม |
| เงื่อนไขหลังจบ | ผลการแข่งขันทั้งหมดและผู้ชนะเลิศถูกแสดงผลบนหน้าจอ |

### UC-24: แสดงความคิดเห็น (Comment on Tournament)

| หัวข้อ | รายละเอียด |
|--------|-----------|
| ชื่อกรณีการใช้งาน | UC-24: แสดงความคิดเห็น (Comment on Tournament) |
| ตัวแสดงแทน (Actors) | สมาชิก (Member) |
| เงื่อนไขก่อนเริ่ม | ผู้ใช้งานเข้าสู่ระบบแล้ว และทัวร์นาเมนต์มีอยู่ในระบบ |
| ลำดับขั้นตอนการทำงาน | 1. ผู้ใช้งานอยู่ในหน้ารายละเอียดทัวร์นาเมนต์ ส่วนความคิดเห็นพร้อมช่องพิมพ์ถูกแสดงผล <br> 2. ผู้ใช้งานพิมพ์ความคิดเห็นและกดปุ่มส่ง <br> 3. ระบบดำเนินการตรวจสอบว่าข้อความไม่ว่างเปล่า และบันทึกความคิดเห็นลงฐานข้อมูล <br> 4. ความคิดเห็นใหม่ถูกแสดงผลในส่วนความคิดเห็น พร้อมชื่อผู้เขียนและวันเวลา |
| เงื่อนไขหลังจบ | ความคิดเห็นถูกบันทึกและแสดงผลในหน้ารายละเอียดทัวร์นาเมนต์ |

### UC-25: รายงานเนื้อหาไม่เหมาะสม (Report Content)

| หัวข้อ | รายละเอียด |
|--------|-----------|
| ชื่อกรณีการใช้งาน | UC-25: รายงานเนื้อหาไม่เหมาะสม (Report Content) |
| ตัวแสดงแทน (Actors) | สมาชิก (Member) |
| เงื่อนไขก่อนเริ่ม | ผู้ใช้งานเข้าสู่ระบบแล้ว และมีเนื้อหาที่ต้องการรายงาน |
| ลำดับขั้นตอนการทำงาน | 1. ผู้ใช้งานกดปุ่มรายงาน (Report) บนความคิดเห็นที่ไม่เหมาะสม <br> 2. แบบฟอร์มรายงานถูกแสดงผล ประกอบด้วยช่องระบุเหตุผลของการรายงาน <br> 3. ผู้ใช้งานกรอกเหตุผลและกดปุ่มส่ง <br> 4. ระบบดำเนินการบันทึกรายงานลงฐานข้อมูลในสถานะ "Pending" พร้อมข้อความแจ้งสำเร็จ |
| เงื่อนไขหลังจบ | รายงานปัญหาถูกสร้างขึ้นในสถานะ "Pending" รอการพิจารณาจากผู้ดูแลระบบ |

|--------|-----------|

| เงื่อนไขหลังจบ | สถานะผู้ใช้งานถูกเปลี่ยนแปลง (Active/Banned) และ Audit Log ถูกบันทึก |

| ลำดับขั้นตอนการทำงาน | 1. ผู้ดูแลระบบเลือกรายงานที่ต้องการดำเนินการ <br> 2. ข้อมูลรายละเอียดของรายงานถูกแสดงผล <br> 3. ผู้ดูแลระบบกดปุ่ม "Resolve" (ดำเนินการแล้ว) หรือ "Dismiss" (ยกเลิก) <br> 4. ระบบดำเนินการเปลี่ยนสถานะรายงานในฐานข้อมูล และ Audit Log ถูกบันทึกโดยอัตโนมัติ |
| เงื่อนไขหลังจบ | สถานะรายงานถูกเปลี่ยนเป็น "Resolved" หรือ "Dismissed" |

### UC-34: ลบความคิดเห็น (Delete Comment)

| หัวข้อ | รายละเอียด |
|--------|-----------|
| ชื่อกรณีการใช้งาน | UC-34: ลบความคิดเห็น (Delete Comment) |
| ตัวแสดงแทน (Actors) | ผู้ดูแลระบบ (Admin) |
| เงื่อนไขก่อนเริ่ม | ผู้ดูแลระบบเข้าสู่ระบบแล้ว และมีความคิดเห็นที่ถูกรายงานหรือไม่เหมาะสม |
| ลำดับขั้นตอนการทำงาน | 1. ผู้ดูแลระบบพบความคิดเห็นที่ไม่เหมาะสมผ่านหน้าจัดการรายงานหรือหน้ารายละเอียดทัวร์นาเมนต์ <br> 2. ผู้ดูแลระบบกดปุ่ม "Delete Comment" <br> 3. กล่องยืนยันการลบถูกแสดงผล และผู้ดูแลระบบทำการยืนยัน <br> 4. ระบบดำเนินการลบความคิดเห็นออกจากฐานข้อมูล และ Audit Log ถูกบันทึกโดยอัตโนมัติ |
| เงื่อนไขหลังจบ | ความคิดเห็นถูกลบออกจากระบบ และ Audit Log ถูกบันทึก |

### UC-35: ดูบันทึกการดำเนินการ (View Audit Logs)

| หัวข้อ | รายละเอียด |
|--------|-----------|
| ชื่อกรณีการใช้งาน | UC-35: ดูบันทึกการดำเนินการ (View Audit Logs) |
| ตัวแสดงแทน (Actors) | ผู้ดูแลระบบ (Admin) |
| เงื่อนไขก่อนเริ่ม | ผู้ดูแลระบบเข้าสู่ระบบแล้ว และมีสิทธิ์ Staff |
| ลำดับขั้นตอนการทำงาน | 1. ผู้ดูแลระบบเข้าสู่หน้า Audit Logs ผ่าน Admin Panel <br> 2. ระบบดำเนินการดึงข้อมูลบันทึกการดำเนินการทั้งหมดจากฐานข้อมูล <br> 3. รายการบันทึกถูกแสดงผลในรูปแบบตาราง ประกอบด้วย ผู้ดำเนินการ ประเภทการกระทำ เป้าหมาย และวันเวลา เรียงจากล่าสุดไปเก่าสุด <br> 4. ผู้ดูแลระบบสามารถตรวจสอบประวัติการดำเนินการทั้งหมดของผู้ดูแลระบบทุกคนได้ |
| เงื่อนไขหลังจบ | รายการบันทึกการดำเนินการถูกแสดงผลอย่างครบถ้วน |
