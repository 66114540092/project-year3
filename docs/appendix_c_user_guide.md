# คู่มือการใช้งานของระบบ

คู่มือการใช้งานทั้งหมดของระบบจัดการการแข่งขันและโหวตแบบเรียลไทม์ (BattleHub) มีขั้นตอนการใช้งาน สามารถแบ่งออกเป็น 4 ส่วน ดังนี้

## ค.1 ส่วนของสมาชิก (Member)
ส่วนสำหรับผู้ใช้งานทั่วไปที่ต้องการสมัครสมาชิกและจัดการข้อมูลส่วนตัว

1.  **การสมัครสมาชิก (Sign Up):** ผู้ใช้กรอก Username, Email, และ Password เพื่อสร้างบัญชีใหม่
    *(รูปที่ ค.1 หน้าต่างแบบฟอร์มสมัครสมาชิก)*

2.  **การเข้าสู่ระบบ (Login):** ผู้ใช้กรอก Username และ Password เพื่อเข้าใช้งาน
    *(รูปที่ ค.2 หน้าต่างเข้าสู่ระบบ)*

3.  **การจัดการโปรไฟล์ (Profile):** ผู้ใช้สามารถแก้ไขรูปภาพประจำตัว (Avatar) และข้อมูลสังเขป (Bio) ได้
    *(รูปที่ ค.3 หน้าต่างแก้ไขข้อมูลโปรไฟล์)*

## ค.2 ส่วนของผู้จัดทัวร์นาเมนต์ (Host)
ส่วนสำหรับผู้ที่ต้องการสร้างและดำเนินการแข่งขัน

1.  **การสร้างทัวร์นาเมนต์:** ผู้ใช้กดปุ่ม "Create" และกรอกรายละเอียดการแข่งขัน เช่น ชื่อ, กติกา, จำนวนผู้เข้าแข่งขัน
    *(รูปที่ ค.4 หน้าต่างฟอร์มสร้างทัวร์นาเมนต์)*

2.  **การเพิ่มผู้เข้าแข่งขัน:** ผู้ใช้สามารถอัปโหลดรูปภาพผู้เข้าแข่งขันเข้าสู่ระบบได้
    *(รูปที่ ค.5 หน้าต่างจัดการรายชื่อผู้เข้าแข่งขัน)*

3.  **การเริ่มห้อง Lobby:** ผู้ใช้เปิดห้องรอ (Lobby) เพื่อให้ผู้เข้าแข่งขันคนอื่นเข้าร่วมผ่าน PIN Code
    *(รูปที่ ค.6 หน้าต่าง Waiting Lobby แสดงรหัส PIN)*

## ค.3 ส่วนของการแข่งขันและโหวต (Competition & Voting)
ส่วนสำหรับกระบวนการแข่งขันและการตัดสินผล

1.  **การเข้าร่วมแข่งขัน:** ผู้เข้าร่วมกรอก PIN Code เพื่อเข้าสู่ห้อง Lobby
    *(รูปที่ ค.7 หน้าต่างกรอก PIN Code เพื่อเข้าร่วม)*

2.  **การโหวต (Voting):** เมื่อการแข่งขันเริ่ม ผู้ชมและผู้เล่นสามารถกดโหวตให้กับฝ่ายที่ชอบได้แบบ Real-time
    *(รูปที่ ค.8 หน้าต่างการแข่งขันและปุ่มกดโหวต)*

3.  **สรุปผลการแข่งขัน:** เมื่อจบการแข่งขันทุกรอบ ระบบจะแสดงรายชื่อผู้ชนะเลิศ (Champion)
    *(รูปที่ ค.9 หน้าต่างสรุปผลผู้ชนะเลิศ)*

## ค.4 ส่วนของผู้ดูแลระบบ (Admin)
ส่วนสำหรับผู้ดูแลระบบในการตรวจสอบและจัดการความเรียบร้อย

1.  **แดชบอร์ด (Dashboard):** แสดงภาพรวมสถิติของระบบ กราฟผู้ใช้งาน และรายการล่าสุด
    *(รูปที่ ค.10 หน้าต่าง Admin Dashboard)*

2.  **การจัดการผู้ใช้งาน:** ผู้ดูแลระบบสามารถดูรายชื่อและสั่งระงับการใช้งาน (Ban) ผู้ใช้ที่ทำผิดกฎได้
    *(รูปที่ ค.11 หน้าต่างตารางจัดการรายชื่อผู้ใช้งาน)*
